# English Learner

基于 React、TypeScript 和 Vite 的英语学习工具，支持单词学习、自定义词库、错词回顾、阅读和听力练习。

## 运行

```bash
npm ci
npm run dev
```

## 验证与构建

```bash
npm run lint
npm run build
```

学习进度和自定义内容保存在浏览器本地。查词、翻译和部分语音功能会访问第三方服务；请勿将含敏感内容的文本用于在线查询。

仓库包含 GitHub Pages 发布工作流。工具依赖和构建命令以 `package.json` 为准。
